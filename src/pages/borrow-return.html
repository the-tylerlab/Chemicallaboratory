ยืม-คืนพัสดุและเคมี

ระบบบันทึกรายการยืม-คืนสารเคมีและอุปกรณ์วิทยาศาสตร์ พร้อมตัดสต็อกอัตโนมัติ

บันทึกรายการยืม-คืน

ทำรายการยืมสารเคมี/อุปกรณ์เพื่อเบิกใช้ หรือบันทึกส่งคืนเข้าสต็อก

โหมดบุคคลทั่วไป (Guest / Public)

บุคคลทั่วไปสามารถสืบค้นและดูข้อมูลสารเคมี/พัสดุและ SDS ได้อย่างเดียว หากต้องการทำรายการยืม-คืนพัสดุ กรุณาเข้าสู่ระบบด้วย Teacher ID

ประวัติการทำรายการล่าสุด

แสดงประวัติการยืมและการส่งคืนสินค้าพัสดุวิทยาศาสตร์แบบเรียลไทม์
