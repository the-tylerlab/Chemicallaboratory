MODAL: VERSION HISTORY DIALOG ========================================== -->

ประวัติการอัปเดตระบบ (Version History)

v1.9.8 25 สิงหาคม 2569 (ล่าสุด)
  • แก้ไขการแสดงผลบนอุปกรณ์เคลื่อนที่ (Mobile Responsiveness UI Fix): แก้ไขปัญหาการแสดงผลกล่องค้นหา, ปุ่มต่างๆ, และหน้าจองห้องปฏิบัติการเมื่อแสดงบนหน้าจอมือถือและแท็บเล็ต
  • ปรับปรุงประสิทธิภาพไวยากรณ์ (CSS Code Quality): แก้ไขปัญหารูปแบบไวยากรณ์ Transition ที่ไม่ถูกต้องและปิดท้ายแท็กที่สูญหายทั้งหมด
v1.9.7 24 สิงหาคม 2569
  • ปิดระบบ PWA และ Offline Cache: ยกเลิกการใช้งาน Service Worker และ Manifest เพื่อลดปัญหาแคชสะสม และบังคับให้เบราว์เซอร์ดึงข้อมูลใหม่เสมอ (Cache-Control)
  • แก้ไขการแสดงผลแถบเมนู (Sidebar Active UI): แก้ไขปัญหาการชนกันของคลาส CSS ที่ทำให้แถบเมนูด้านซ้ายแสดงสีเข้ม/อ่อนไม่สม่ำเสมอกัน
v1.9.1 1 กรกฎาคม 2569
  • ระบบพิมพ์สติกเกอร์บาร์โค้ด QR Code แบบแอนิเมชันพร้อมเสียง (Animated QR Code Label Printer): เพิ่มป๊อปอัพและเสียงจำลองเครื่องพิมพ์สติกเกอร์ฉลากติดขวดสารเคมีและอุปกรณ์เมื่อกดสั่งพิมพ์
v1.9.0 26 มิถุนายน 2569
  • ระบบล้างข้อมูล Admin (Admin Data Clearing): เพิ่มระบบล้างฐานข้อมูลแยกตามแต่ละโมดูลพร้อมช่องกรอกรหัสยืนยันความปลอดภัยเพื่อป้องกันข้อมูลสูญหาย
  • สรุปข้อมูลยอดราคารวมตารางสั่งซื้อสะสม (Committed PO Summary): เพิ่มแถบรายละเอียดราคารวม, ส่วนลดสะสม, และราคาสุทธิหลังหักส่วนลดอย่างสมบูรณ์แบบ
  • คู่มือเตรียมสารเคมีในระบบ Catalyst: แชทบอทวิเคราะห์คำนวณสูตรเตรียมสารละลายและความเข้มข้นอัตโนมัติ
v1.8.0 25 มิถุนายน 2569
  • ป๊อปอัพใบยืนยันการจองหลังจองห้องแล็บสำเร็จ (Booking Confirmation Modal): เพิ่มระบบหน้าต่างยืนยันความสำเร็จ (Booking Confirmation Modal) ทันทีหลังส่งคำขอจอง พร้อมข้อมูลสรุปและคำแนะนำเตือนใจความสำคัญให้ผู้ใช้บันทึกภาพหน้าจอ (Capture) ไว้เป็นหลักฐานเพื่อแสดงต่อเจ้าหน้าที่ห้องปฏิบัติการอย่างชัดเจน
v1.7.0 23 มิถุนายน 2569
  • ระบบจำแนกของเสียและคู่มือการจัดเก็บเคมีร่วมกัน (CU WasteTrack & Storage Guide): เพิ่มแถบช่วยจำแนกของเสียห้องปฏิบัติการ 17 ประเภทของจุฬาลงกรณ์มหาวิทยาลัย และระบบแนะนำจัดเก็บสารเคมีร่วมตามความเข้ากันได้ 11 กลุ่มความเข้ากันได้ (SHECU)
  • ผู้ช่วย AI แชทบอท Catalyst และเครื่องคำนวณสูตรเคมี: ติดตั้งแชทบอทให้คำปรึกษาเคมี/ปฐมพยาบาลเบื้องต้น พร้อมเครื่องดุลสมการและคำนวณมวลโมเลกุลอัตโนมัติ
v1.6.0 10 พฤษภาคม 2569
  • ระบบจองห้องปฏิบัติการ (Lab Booking Suite): เปิดใช้งานระบบตารางจองคาบเวลาเข้าใช้ห้องแล็บ คัดกรองและแบ่งสิทธิ์ครูและเจ้าหน้าที่
  • การจัดการคลังสารเคมีแจ้งเตือนหมดอายุ: ติดตั้งระบบแจ้งเตือนสต็อกขั้นต่ำ (Min Stock) และแจ้งรายการสารเคมีใกล้และหมดอายุอัตโนมัติ
